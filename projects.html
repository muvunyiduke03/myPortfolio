ALUGate

ALUGate is a mobile app that connects ALU students with startups looking for part-time help. Startups post opportunities, and students browse them, save the ones they like, apply, and track their applications. It's built with Flutter and uses Firebase for accounts and data.

I designed and built the application from layout and styling to the logic implementation of the application using Flutter and Firebase.

Visit Project

Kivu HQMS

This is a Flask-based web application that patients use to book appointments at hospitals. Admins (doctors, nurses and receptionists) use it to manage the daily queue and update the status of patients' appointments.

I designed and built the application from layout and styling to the logic implementation of the application using Python (Flask), MySQL 8, SQLAlchemy and Flask-Migrate, HTML/CSS/JavaScript, Docker and Docker Compose, GitHub Actions.

Imanzi Kitchen

A fast, mobile friendly website template built for restaurants, featuring an online menu with photos and prices, a one tap WhatsApp booking button, embedded location and hours, and a photo gallery designed to help restaurants convert online visitors into walk-ins and bookings.

I designed and built the full frontend, from layout and styling to the WhatsApp integration and mobile-responsive design.
